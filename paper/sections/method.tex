\section{Method}
\label{sec:method}

We present \styleshield{}, a framework for continuous and controllable AI-to-human text style transfer.
Figure~\ref{fig:architecture} provides an overview.
The system consists of three components: (1)~a DiT backbone pretrained with flow matching (\S\ref{sec:backbone}), (2)~cross-attention adapters conditioned on a frozen Qwen encoder (\S\ref{sec:conditioning}), and (3)~detector-in-the-loop training with SDEdit-style inference (\S\ref{sec:training}).
We additionally describe the allocator algorithm for long-document transfer (\S\ref{sec:allocator}).

\subsection{Flow Matching Backbone}
\label{sec:backbone}

\styleshield{} builds on \langflow{}, a Diffusion Transformer (DiT) for Chinese text generation trained with the flow matching objective~\citep{lipman2023flow, karras2022elucidating}.
The backbone operates in continuous token embedding space: each token $w_i$ is mapped to a $d$-dimensional embedding $\mathbf{e}_i \in \mathbb{R}^d$ via a learned vocabulary embedding layer with normalized embeddings.

\paragraph{Architecture.}
The DiT consists of $N{=}12$ transformer blocks, each containing multi-head self-attention with rotary positional embeddings (RoPE), a feed-forward network (FFN) with GELU activation, and adaptive layer normalization (adaLN-Zero) conditioned on a timestep embedding.
A sinusoidal timestep embedder maps the noise schedule parameter $\gamma$ to a conditioning vector $\mathbf{c}_\gamma = \mathrm{SiLU}(\mathrm{MLP}(\mathrm{sinusoidal}(\gamma)))$, which modulates each block via learned shift, scale, and gate parameters:
\begin{equation}
    \mathbf{x}' = (1 + \mathbf{s}_{\gamma}) \odot \mathrm{LN}(\mathbf{x}) + \mathbf{b}_{\gamma}
\end{equation}
where $\mathbf{s}_\gamma, \mathbf{b}_\gamma$ are predicted from $\mathbf{c}_\gamma$.
A final adaLN layer projects to vocabulary logits.
The bias skip connection~\citep{karras2022elucidating} adds a residual path: $\mathrm{logits} = f_\theta(\mathbf{z}, \gamma) + c_{\mathrm{skip}}(\gamma) \cdot \mathbf{z} \mathbf{W}_{\mathrm{emb}}^\top$, where $c_{\mathrm{skip}}(\gamma) = \exp\left(\frac{\mathrm{softplus}(-\gamma) - \gamma}{2}\right)$.

\paragraph{Noise Schedule and Gumbel Proposal.}
Following the EDM formulation~\citep{karras2022elucidating}, the forward noising process at noise level $\gamma$ is:
\begin{equation}
    \mathbf{z}_\gamma = \alpha(\gamma)\, \mathbf{x} + \sigma(\gamma)\, \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})
\end{equation}
where $\alpha(\gamma) = \sqrt{\text{sigmoid}(-\gamma)}$ and $\sigma(\gamma) = \sqrt{\text{sigmoid}(\gamma)}$.
During training, noise levels are sampled from a learned Gumbel proposal distribution $\gamma \sim \mathrm{Gumbel}(\mu, \beta)$, which concentrates samples on noise levels where the model learns most efficiently.

\subsection{Qwen Cross-Attention Conditioning}
\label{sec:conditioning}

A key design goal is preserving the semantic content of the source AI text during style transfer.
We achieve this by conditioning the denoising process on representations extracted from a frozen Qwen-2.5-7B-Instruct model~\citep{qwen2024qwen25}.

\paragraph{Qwen Encoder.}
We extract hidden states at an intermediate layer $L$ of the Qwen model (default $L{=}14$ out of 28 layers).
The input AI text is tokenized with the Qwen tokenizer and passed through layers $0$ to $L{-}1$; the resulting hidden states $\mathbf{H}_{\mathrm{qwen}} \in \mathbb{R}^{B \times S_q \times 3584}$ serve as semantic conditioning.
The Qwen model is kept entirely frozen throughout training.
The choice of split layer $L$ balances between surface-level features (low $L$) and high-level semantics (high $L$); we ablate this choice in \S\ref{sec:ablation}.

\paragraph{Cross-Attention Adapters.}
We insert a cross-attention adapter module after each DiT self-attention block.
Each adapter performs multi-head cross-attention where queries come from the flow tokens and keys/values come from the projected Qwen hidden states:
\begin{align}
    \mathbf{K}, \mathbf{V} &= \mathrm{split}\!\left(\mathbf{W}_{kv}\, \mathrm{proj}(\mathbf{H}_{\mathrm{qwen}})\right) \\
    \mathbf{Q} &= \mathbf{W}_q\, \mathrm{LN}(\mathbf{x}) \\
    \mathbf{x}' &= \mathbf{x} + g(\mathbf{c}_\gamma) \odot \mathrm{Attn}(\mathbf{Q}, \mathbf{K}, \mathbf{V})
\end{align}
where $\mathrm{proj}: \mathbb{R}^{3584} \to \mathbb{R}^{768}$ is a learned linear projection (the \texttt{cond\_proj} layer), and $g(\mathbf{c}_\gamma)$ is a \textbf{zero-initialized gate} that depends on the timestep conditioning.
This zero initialization is critical: at the start of training, the adapters have no effect ($g \equiv \mathbf{0}$), so the model is exactly equivalent to the pretrained \langflow{}.
The gate gradually opens as training progresses, allowing the model to smoothly learn to incorporate semantic conditioning without catastrophic forgetting of the pretrained generation capability.

\subsection{Training and Inference}
\label{sec:training}

\paragraph{Data Construction.}
We construct parallel AI-human text pairs across three domains: social media discussions, news articles, and academic abstracts.
For each domain, we collect human-written texts and use Qwen-2.5-7B-Instruct to rewrite them into AI style, producing pairs $(x_{\mathrm{AI}}, x_{\mathrm{human}})$.
The resulting multi-domain dataset contains approximately 61K pairs.

\paragraph{Training Objective.}
The base training loss is the standard denoising cross-entropy:
\begin{equation}
    \mathcal{L}_{\mathrm{CE}} = -\sum_{i=1}^{L} \log p_\theta(w_i^{\mathrm{hu}} \mid \mathbf{z}_\gamma, \gamma, \mathbf{H}_{\mathrm{qwen}})
\end{equation}
where $\mathbf{z}_\gamma$ is obtained by interpolating between the AI and human token embeddings:
$\mathbf{z}_\gamma = (1-t) \cdot \mathbf{e}_{\mathrm{AI}} + t \cdot \mathbf{e}_{\mathrm{human}}$
and adding noise at level $\gamma$.
The target is the human text $w^{\mathrm{hu}}$.

\paragraph{Detector-in-the-Loop Reward.}
After a warmup period (5{,}000 steps), we introduce an auxiliary reward signal from a BERT-based AIGC detector.
Every $k$ steps, we perform inference on a batch of AI inputs, run the generated text through the detector, and compute a reward:
\begin{equation}
    \mathcal{R}_{\mathrm{det}} = 1 - \pai(\hat{x})
\end{equation}
where $\pai(\hat{x})$ is the detector's estimated probability that the generated text $\hat{x}$ is AI-written.
This reward is incorporated with weight $\lambda_{\mathrm{det}}{=}0.1$ into the total loss:
$\mathcal{L} = \mathcal{L}_{\mathrm{CE}} + \lambda_{\mathrm{det}} \cdot (1 - \mathcal{R}_{\mathrm{det}})$.

\paragraph{SDEdit-Style Inference.}
At inference time, we perform style transfer using the SDEdit paradigm~\citep{meng2022sdedit} adapted to token embeddings:
\begin{enumerate}
    \item Embed the input AI text using the vocabulary embedding layer.
    \item Add noise at level $\gamma_{\mathrm{start}}$: $\mathbf{z}_0 = \alpha(\gamma_{\mathrm{start}})\, \mathbf{e}_{\mathrm{AI}} + \sigma(\gamma_{\mathrm{start}})\, \boldsymbol{\epsilon}$.
    \item Iteratively denoise using the EDM Euler sampler over $T{=}64$ steps from $\gamma_{\mathrm{start}}$ down to $\gamma_{\min}$, with Qwen conditioning at each step.
    \item Decode the final logits via argmax to obtain the transferred text.
\end{enumerate}
The parameter $\gamma_{\mathrm{start}}$ acts as a continuous control knob: lower values produce outputs closer to the original AI text (higher semantic preservation, lower evasion), while higher values push the output further toward natural human style (stronger evasion, slightly lower similarity).

\subsection{Allocator: Long-Document Style Transfer}
\label{sec:allocator}

Real-world AIGC detection is often applied to long documents (e.g., essays, reports) that exceed the input length limit of both detectors and our model (typically 512 tokens).
We propose an \emph{allocator} algorithm that enables style transfer on arbitrarily long texts with a user-specified target detection rate.

\paragraph{Algorithm.}
Given a document $D$ and a target rate $r_{\mathrm{target}}$:
\begin{enumerate}
    \item \textbf{Chunk}: Split $D$ into overlapping chunks $\{c_1, \ldots, c_n\}$ of $\leq$512 tokens.
    \item \textbf{Score}: Compute $\pai(c_i)$ for each chunk using the AIGC detector.
    \item \textbf{Prioritize}: Sort chunks by $\pai(c_i)$ in descending order.
    \item \textbf{Rewrite}: Greedily rewrite the highest-$\pai$ chunks using \styleshield{} with adaptive $\gamma$, re-scoring after each rewrite, until the weighted average $\pai$ across all chunks falls below $r_{\mathrm{target}}$.
\end{enumerate}
The adaptive $\gamma$ strategy starts with a moderate value ($\gamma{=}6.0$) and escalates if the rewritten chunk still exceeds the target, trying $\gamma \in \{6.0, 6.5, 7.0, 7.5\}$ in sequence.
A tolerance parameter ($\epsilon{=}0.02$) and an overshoot-skip heuristic prevent unnecessary rewrites when the target is nearly met.
